No task is ready until its requirement, acceptance commands and prerequisites
have been reconciled with the actual project. Add one record per bounded task.
Order ready tasks by dependency and owner priority.

- State: needs-planning
- Requirement or confirmed defect: To be linked

- Publication requirement and intended destination: To be specified
- Last attempt and exact failure: None recorded
- Next experiment if blocked: To be specified
- Completion evidence and resulting revision: None recorded

States are needs-planning, ready, in-progress, blocked, completed and deferred.
A blocked record names the actual failed command or missing prerequisite and
the condition that permits another attempt. Completed records retain their
validation and publication evidence. An empty ready queue means the project
needs planning or an owner decision. It never requires a filler commit.
