# Template Library

**Content type:** Informative template index

The remaining chapters are reusable starting points for project-owned records.
They are not completed WSP records, project requirements, approvals, or
verification evidence.

Copy a required template into the adopting project, replace every placeholder,
assign project ownership and status, and control the resulting artifact under
the project's process. Do not edit the pinned WSP submodule to complete a
template.

## Included Templates

- ADR template;
- requirement template;
- WSP adoption-record template;
- release-readiness record;
- Design for Security;
- test report; and
- LaTeX test-case definitions and template, supplied as source files in the
  `testing/` directory.

The template chapters are grouped at the end of the release PDF so examples
and placeholders remain visually separate from normative WSP requirements.
